# Each HID driver's init sets its XRAM address to $FFFF, which means unmapped.
# A driver whose init never ran holds zero instead, which is a real address, so
# it writes its block over XRAM 0. mode3_8bpp.rp6502 maps no HID device, its
# XRAM records start at $0100, and it halts on STP once the mode is programmed,
# so anything written to XRAM 0 came from a driver.

run 30
poke xram:0 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5

mouse move 5 5
mouse buttons 1
mouse wheel 3
run 5
peek xram:0 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5

tablet at 100 100 1
tablet touch 60,60
tablet wheel 2
run 5
peek xram:0 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5 $A5

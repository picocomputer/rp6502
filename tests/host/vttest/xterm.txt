# The screens of the vttest walk that differ from xterm's (patch 412) on
# purpose: the screen's name, the digest of its differences from
# screens/xterm.txt, and why. vtrun fails on any other difference, on one of these that has
# changed, and on one that no longer happens.

# Bytes 0x80 to 0xFF are the code page's glyphs, so the sets vttest puts in
# GR with LS1R, LS2R and LS3R do not show there.
3_10-01 3081B9D9 GR is the code page
# ENQ has no answerback, and the console draws it as its CP437 glyph.
6_1-01 D74B1D82 ENQ is drawn
# ERM: the console keeps ECMA-48's erasure mode, which xterm ignores, so
# with ERM set an erase clears the guarded cells too.
11.6.7.1_2-01 E9425780 ERM is honored
11.7.1_2-01 E9425780 ERM is honored

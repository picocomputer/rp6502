# The screens of the vttest walk that differ from xterm's on purpose: the
# screen's name, the digest of its differences from screens/xterm.txt, and
# why. vtrun fails on any other difference, on one of these that has
# changed, and on one that no longer happens.

# Bytes 0x80 to 0xFF are the code page's glyphs, so the sets vttest puts in
# GR with LS1R, LS2R and LS3R do not show there.
3_10-01 18EEABBC GR is the code page
# ENQ has no answerback, and the console draws it as its CP437 glyph.
6_1-01 D74B1D82 ENQ is drawn
# DECCARA and DECRARA in stream mode under DECOM: xterm 390 wraps the
# stream at the left and right margins; later xterm wraps it at the screen's
# edges, as the console does, since DEC STD 070 does not tie the stream to
# the margins.
11.3.6_7-02 12A0191B the stream wraps at the screen's edges
11.3.6_11-02 F9B7BB97 the stream wraps at the screen's edges
# ERM: the console keeps ECMA-48's erasure mode, which xterm ignores, so
# with ERM set an erase clears the guarded cells too.
11.6.7.1_2-01 E9425780 ERM is honored
11.7.1_2-01 E9425780 ERM is honored

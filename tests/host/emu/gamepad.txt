# The gamepad tester continuously redraws every player's state, labelling an
# unplugged slot "Disconnected" and a connected one with its button row.
# Checked through the console rather than the canvas: the terminal carries a
# ~1 Hz cursor blink, so a frame hash would not hold still.

run 40
expect "Disconnected"
expect-not "Select"

# The connected bit is the gate a program reads before anything else. A host
# that knows nothing else about the pad claims nothing else.
pad 0 connect
pad 0 press start
run 20
expect "Select"
peek xram:$FF00 $80 $00 $00 $08

# The dpad and button0 land in their own bytes, and a release clears only
# what it named.
pad 0 release start
pad 0 press up a
run 10
peek xram:$FF00 $81 $00 $01 $00

# Player 1 is a separate ten-byte record and is still unplugged.
peek xram:$FF0A $00

# Analog sticks derive the digital sticks byte the way the firmware does:
# left stick full north is 1, right stick centered is 0.
pad 0 stick 0 -127 0 0
run 10
peek xram:$FF00 $81 $01

# Unplugging blanks the whole record.
pad 0 disconnect
run 20
expect "Disconnected"
peek xram:$FF00 $00 $00 $00 $00 $00 $00 $00 $00 $00 $00

# What a host does know goes in the status nibble, and reconnecting starts
# over from knowing nothing.
pad 1 connect playstation sticks
run 10
peek xram:$FF0A $F0
pad 1 connect eastern
run 10
peek xram:$FF0A $A0
pad 1 connect
run 10
peek xram:$FF0A $80
